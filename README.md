# App Template

React + TypeScript + Vite frontend with TanStack Router and Query; FastAPI + SQLModel backend managed with uv.

Shared code lives in `frontend/src/common` and `backend/src/common`. Features live in each `src/modules` directory. Backend migrations live under `backend/src`.

## Setup

Install the latest stable Node.js, pnpm, uv and Python 3.13.

From the repository root:

```bash
pnpm install
python -c "from shutil import copyfile; copyfile('frontend/.env.example', 'frontend/.env'); copyfile('backend/.env.example', 'backend/.env')"
uv sync --directory backend
pnpm hooks:install
pnpm migrate
```

SQLite is included with Python; its version depends on the Python distribution. The default database is `backend/db/app.db`, ignored by Git. Alembic manages all schema changes.

## Development

Start frontend and backend in separate terminals from the repository root:

```bash
pnpm dev
pnpm dev:backend
```

Alternatively, run the frontend directly:

```bash
pnpm --dir frontend dev --host localhost --port 5173 --strictPort
```

Run the backend directly:

```bash
uv run --directory backend uvicorn main:app --app-dir src --reload --reload-dir src --host 127.0.0.1 --port 8000
```

### URLs

- Home: http://localhost:5173/
- Database: http://localhost:5173/database
- Help: http://localhost:5173/help
- API health: http://localhost:8000/api/health
- API docs: http://localhost:8000/docs

The home page displays the database-backed health response with loading, error and retry states. TanStack Router provides shared navigation and a not-found page.

Production hosting must serve `index.html` as a fallback for frontend routes such as `/help` and `/database`.

Configure `VITE_API_BASE_URL` in `frontend/.env` and `CORS_ORIGINS` in `backend/.env` together. Frontend environment variables are public. Relative database paths resolve from `backend/`, regardless of the invoking directory.

## Quality checks

The pre-commit hook runs `pnpm format:check` on the whole working tree, including unstaged changes. It requires pnpm and uv. Run `pnpm hooks:install` once per checkout to enable it. If formatting fails, run `pnpm format` successfully before retrying the commit.

Run from the repository root:

```bash
pnpm format
pnpm lint
pnpm typecheck
pnpm build
```

- **Frontend:** Biome handles formatting and linting. TypeScript handles type checking.
- **Backend:** Ruff handles formatting and linting; Pyright handles type checking.
- **Python tools:** Installed and executed through uv.

Biome and Ruff use a 150-character line width.

Biome respects `.gitignore` and parses Tailwind directives. Generated output and TypeScript build caches are excluded from version control. GitHub Actions runs the production build (including TypeScript checks), formatting, frontend/backend lint and Python type checks on pushes and pull requests.

Run backend checks independently:

```bash
uv run --directory backend ruff check src
uv run --directory backend ruff format src
uv run --directory backend pyright
```

Biome's type-aware linting does not replace TypeScript type checking.

## Database migrations

From the repository root:

```bash
uv run --directory backend alembic revision --autogenerate -m "describe change"
uv run --directory backend alembic upgrade head
```

Review autogenerated migrations before applying them. Import new SQLModel models in `backend/src/migrations/env.py`.

Never use `create_all`; Alembic owns schema changes.

## Workspace and dependencies

- pnpm is the only JavaScript package manager.
- `pnpm-workspace.yaml` includes `frontend`.
- Commit `pnpm-lock.yaml` and `backend/uv.lock`.
- Use pnpm for all JavaScript dependency and script operations.
- Use uv for all Python dependency and environment operations.
- Do not mix npm and pnpm lockfiles.

The project supports Windows, macOS and Linux. Use cross-platform commands and LF line endings.

## Routing

Routing is file-based using TanStack Router:

| File                      | Route         |
| ------------------------- | ------------- |
| `src/routes/__root.tsx`   | Shared layout |
| `src/routes/index.tsx`    | `/`           |
| `src/routes/help.tsx`     | `/help`       |
| `src/routes/database.tsx` | `/database`   |

Keep page components in `src/modules/`.

The TanStack Router Vite plugin generates `src/routeTree.gen.ts` during development and production builds and supports automatic route code splitting.

Never edit or commit the generated route tree. Build and typecheck generate routes through Vite before running TypeScript, including on a clean checkout.

Build and typecheck scripts must not invoke the standalone `tsr` CLI.

## UI components

shadcn is configured with the `base-nova` style and Base UI primitives. The shared Button uses Base UI while preserving its existing styling.

Shared shadcn components include Button, Label, Textarea and Table. Reuse them from `frontend/src/common/components/ui/`; add other components as needed.

Install components when required:

```bash
pnpm --dir frontend ui add input
```

## Deferred features

Charts, global state and backend outbound HTTP clients remain deferred.

Database inspection is documented in `docs/modules/database/README.md`.

The database query API is read-only but can access all tables. Keep the unauthenticated development server restricted to localhost.
